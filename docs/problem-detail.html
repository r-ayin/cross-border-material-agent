一、任务背景

任务为 商品本地化素材生成：要求参与者构建一个 AI Agent，针对指定商品，自动生成其在目标市场电商平台上架所需的全套本地化素材，本题以AliExpress作为示例。

一件商品从源数据到能够在海外平台上架，中间隔着大量本地化工作：

  • 语言本地化 —— 面向不同市场（如美国、韩国、巴西）产出符合当地语言习惯的商品文案，而非逐字翻译。
  • 视觉素材 —— 产出符合平台规范的主图、详情图与商品视频。
  • 平台适配 —— 将商品准确映射到平台后台的类目与属性体系。
  • 市场适配 —— 完成尺码换算、遵循目标市场的拼写与表达习惯、规避文化禁忌。
  • 事实一致 —— 所有素材中的信息均需忠实于源数据，不得虚构或凭空补全。

这些环节传统上依赖运营、设计、翻译等多个角色协作完成。任务要求参与者构建的 Agent 将上述环节整合为一次自动化运行，端到端交付整套素材。

本次任务的评测环节采用 「机器评测 + 专家评审」 双阶段机制。参与者提交的 Agent 由平台系统以及专家团队，统一运行、统一评测。

 

二、路书导航

1.说明 A：提测标准与环境配置

提测标准

参与者需提交一个 完整的 Agent 代码包，该代码包须能由平台独立运行，并通过 Agent 自动产出全部待评测素材。代码包需满足以下规范要求：

  • 请上传 ZIP 格式的产物包（≤ 100 MB），包内须包含名为 agent.py、agent.js、agent.jar 或 agent（Go 编译产物，无后缀）的入口文件。
  • 产物包需自带全部运行依赖，平台将根据文件后缀自动识别运行时并启动程序。
  • 启动时平台通过 --prompt 参数传递一段自然语言指令，您的程序需从中提取输入数据路径与输出路径并完成任务。
  • 程序正常完成须以退出码 0 退出，失败则返回非 0 退出码。
  • 所有产出素材须严格遵循规定的命名规范，且 字段可解析，以便平台定位各类素材并进行自动评测。

环境配置

运行环境为 Linux(Debian 12 x86_64),已预装且仅支持 JDK 17、Python 3.12、Node.js 22、Go 1.22。平台根据入口文件后缀自动选择运行时(.py 使用 Python、.js 使用 Node.js、.jar 使用 Java、无后缀 ELF 二进制识别为 Go 编译产物),并以 --prompt "..." 传递包含输入输出路径的自然语言指令,程序需自行解析 prompt 内容完成任务。

以下为具体说明:

  • 产物所在目录须命名为agent,产物包须为 ZIP 格式,压缩后大小不超过 100 MB。
  • 入口文件必须位于根目录,命名为 agent.py、agent.js、agent.jar(须声明 Main-Class)或 agent(Go 编译产物,无后缀)。
  • 根目录须包含 agent.json 文件,格式为 {"runtime":"name","version":"x.y.z"}。runtime 由实现产物使用的运行时决定,均为小写,有效取值为java/python/node/go;version 为语义化版本号,x.y.z 三部分仅支持数字,示例:1.0.0。
  • 根目录须根据实现提供对应的依赖声明文件:Java 提供 pom.xml,Python 提供 requirements.txt,Node.js 提供 package.json,Go 提供 go.mod。
  • 在提供依赖声明文件的同时,所有依赖必须打包在 ZIP 内并已适配运行环境,运行时环境不提供网络安装能力。
  • 环境变量 DASHSCOPE_API_KEY 已预置，作为模型调用的API Key；必须从环境变量中读取使用，其他方式无法成功调用模型。
  • 环境变量 DASHSCOPE_BASE_URL 及 OPENAI_BASE_URL已预置，分别作为通过DashScope API/兼容 OpenAI 格式的 Chat API 调用模型的调用地址；DASHSCOPE_BASE_URL 环境变量以 /api/v1 结尾，OPENAI_BASE_URL 以/v1结尾；必须从环境变量中读取使用，其他方式无法成功调用模型。
  • 环境变量 AGENT_LOG_DIR 指定日志输出目录，相关日志请写入该目录下的 agent.log 中
  • 模型使用范围：机器评测环节仅允许调用规定以下模型列表,其他模型无法成功调用。

四、具体评测维度参考

本任务包含机器评测和专家评审两个维度。

  • 机器评测阶段，国内站 – 千问 AI 平台（www.qianwenai.com ）与海外站 – Qwen Cloud（www.qwencloud.com ）分别独立打榜、各自排名。
  • 进入专家评审阶段后，两个榜单各取前 30 名作品汇总，由专家统一盲评、拉通排名，最终评选出 Top 5 并决出金、银、铜奖。

1. 机器评测（公开排名）

机器评测用户提交的最新作品，保留整个过往评审中最高成绩作品及对应排名，以此作为入围依据。具体考察维度如下：

机器评测总分 = Σ（各维度得分 × 对应权重），机器评测排名以总分为准。

维度 范畴 子维度 评判方式 权重
A1 内容合规性 判定对象为全部文本素材、图片 / 视频内可识别文字，以及画面视觉元素；仅按平台素材内容合规规则判定，不做法律与知识产权判断。规则分文本、图像两个通道，需自行搜索 AliExpress 的平台上架规则。 整体判定 标题、详情文案、图片 / 视频内叠加文字与画面视觉元素均不出现任一违规项，即为合规。 25%
A2 素材规格达标 校验 Agent 产出素材的内容完整性与物理规格；不判压缩包打包方式，也不判内容对错。 文本内容完整性（文件大小 < 1MB）；主图规格（jpeg/png，≥ 800×800 px）；图片规格（jpeg/png，宽高均 > 260 px，单张 ≤ 5 MB）；视频（文件存在且可正常播放，mp4/mov，单个视频 < 200MB） 按子维度评分，符合规范即得分。 20%
A3 类目与属性准确性 校验类目名称与商品属性、销售属性枚举值；仅做"选手输出对比标准答案"的校验，算法不自行判断类目归属。 叶子类目正确性；商品属性命中（各属性 key/value）；销售属性（规格分类值）命中 按子维度评分，符合规范即得分。 18%
A4 本地化适配 主图 / 详情图视觉、文案语气用词、拼写、尺码度量、文化禁忌等文化差异。 背景规范；文案用词合规；拼写与本地用词；尺码体系；度量单位；文化禁忌·性别与体型；渠道场景本土化 按子维度评分，符合规范即得分。 15%
A5 商品事实一致性 文本素材做信息来源检查；图片 / 视频内叠加文字仅抽检。 来源匹配商品源数据；标注与源数据中的展示匹配 可核验属性均需标明来源且与标准答案一致；未标注、与源数据不一致，或与标准答案不一致，均判为不对。 10%
A6 出图可用率 一次性生成的全部图片。 "可用"定义：符合平台图片需求规格，且质量上无重大瑕疵。 一次性生成图中"可用"比例达到规定阈值（≥ 80%）为合格，低于阈值为不合格。 7%
A7 出视频可用性 一次性生成的全部视频。 "可用"定义：符合平台视频需求规格，可正常播放且无重大瑕疵。 视频可正常播放且不触发任一不可容忍瑕疵，即为可用。 5%

2. 专家评审（Top 30 盲评）

两个榜单各取前 30 名的作品汇总进入专家评审阶段，由行业专家统一盲评、拉通排名，评审维度如下：

专家评审总分 = Σ（各维度得分 × 对应权重）。

维度 说明 权重
Agent 使用体验 交互流程、稳定性与整体使用顺畅度。 15%
图片素材效果 主图与详情图的可用性及呈现效果。 30%
视频素材效果 商品视频的可用性及呈现效果。 20%
整体策略 本地化与素材生成策略的合理性、完整性与竞争力。 35%

专家评审后，从入围作品中评选出最终 Top 5，决出金（1 名）、银（2 名）、铜奖（2 名）。

 

五、可能的任务问题排查

在任务完成过程中，如遇提交失败等问题，可能是因为一下原因，请优先按以下清单进行排查：

  1. 是否按规调用了千问 AI 平台 API KEY。
  2. 产出文件名称是否符合规范。
  3. 素材产出是否完整。
  4. 提交的代码包是否符合要求。
  5. Agent 运行时间是否超过 30 min。
  6. 调用模型不符合需求，检查输入参数是否符合赛题要求和模型限制。
  7. DASHSCOPE_BASE_URL 环境变量以 /api/v1 结尾，OPENAI_BASE_URL 以/v1结尾，调用时请注意 URL 中是否重复拼接或出现格式错误。
  8. 代码包依赖是否完整。

以上仅为常见示例，不为问题枚举，如出现都未包含的情况，请基于Agent作品自查。
