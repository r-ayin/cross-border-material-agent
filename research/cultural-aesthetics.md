## 1. 韩国电商视觉审美：감성（感性/Gamseong）风格

### 1.1 核心特征

| 维度 | 特征描述 |
|------|----------|
| **色彩** | 低饱和度（desaturated）、柔和粉彩（muted pastel）、奶油白/米灰/雾蓝/淡杏为主色调；避免高对比纯色系 |
| **光影** | 自然光主导（window light / golden hour）、柔焦漫射、轻微过曝营造空气感；阴影柔和不硬切 |
| **质感** | 胶片颗粒感（film grain）、轻微暗角、模拟胶片色调（Portra 400/Aura 风格）；纸质/织物纹理叠加 |
| **构图** | 留白充裕、非对称平衡、负空间叙事；产品常偏置而非居中；大量使用手部/局部特写代替全身 |
| **氛围词** | 감성（感性）、여유（从容）、자연스러움（自然）、포근함（温暖舒适）、차분함（沉静） |
| **字体排版** | 细衬线/手写体韩文、小字号、行距宽松；英文仅作点缀装饰；信息密度极低 |
| **模特呈现** | 素人感 > 模特感；微表情、侧脸/背影/遮挡面部；妆容清透裸妆；姿态松弛不刻意摆拍 |

### 1.2 典型应用场景

- **美妆护肤**：Olive Young / Musinsa / Naver Shopping 上的独立品牌（如 Torriden、Beauty of Joseon、Round Lab）——产品置于亚麻布/木托盘上，搭配干花/绿植/陶瓷器皿，背景为奶白墙面或窗边自然光
- **服饰**：Marithe Francois Girbaud Korea、Thisisnorway、Covernat——街拍感但去商业化，模特在咖啡馆/公园/老巷中自然行走，色调统一为暖灰/燕麦色
- **家居生活**：Today's House 平台 UGC 风格——真实用户家中实拍，强调 lived-in 生活痕迹而非样板间完美感
- **食品/饮品**：Cafe 菜单/烘焙品牌——俯拍/45度角，餐具选择哑光陶器，食物旁放书本/手写信/眼镜等个人物品

### 1.3 与其他市场的本质差异

韩国 감성 的核心不是"美"而是"**情绪共鸣**"——视觉服务于唤起观者对某种生活状态的向往（여유로운 삶），而非直接展示产品功能。这与美国的功能直给、巴西的热情外放形成鲜明对比。

## 2. 美国电商视觉审美：Clean / Bold / Direct

### 2.1 核心特征

| 维度 | 特征描述 |
|------|----------|
| **色彩** | 高对比度、纯色背景（白/黑/亮色）突出产品；品牌色大胆使用；CTA 按钮色彩饱和醒目 |
| **光影** | 专业棚拍为主、硬光塑造立体感、阴影清晰可控；产品细节锐利无模糊 |
| **构图** | 中心对称/网格布局、信息层级清晰、F/Z 阅读动线明确；首屏即传达核心价值主张 |
| **模特多元化** | 种族/体型/年龄/性别表达全面多元（DEI 已成行业标配）；模特直视镜头、自信姿态；真实肤色不磨皮 |
| **信息直给** | 标题+卖点+价格+评分+CTA 五要素首屏可见；文案简洁有力（benefit-first）；数据/认证标识前置 |
| **信任元素** | 评论截图、UGC 照片、视频演示、Before/After 对比、专家背书、退换政策徽章 |
| **动态内容** | 短视频/GIF 产品展示、360度旋转、AR 试穿/试用成为标准配置 |

### 2.2 典型平台风格谱系

| 平台类型 | 代表 | 视觉调性 |
|----------|------|----------|
| DTC 品牌 | Glossier, Allbirds, Everlane | 极简白底 + 生活方式场景交替；干净但不冷淡 |
| 大卖场 | Amazon, Walmart | 白底主图强制规范 + A+ Content 富媒体；信息密度高 |
| 运动户外 | Nike, Patagonia, REI | 高能量动作摄影 + 壮美自然景观；色彩饱满 |
| 奢侈品 | SSENSE, Net-a-Porter | 艺术化构图、冷调高级感、模特姿态前卫 |
| Z世代 | TikTok Shop, Depop | 原生手机拍摄感、快节奏剪辑、创作者人格驱动 |

### 2.3 关键原则

- **Clarity over cleverness**：清晰度优先于创意炫技
- **Conversion-driven**：每个视觉元素都有明确的转化目的
- **Authenticity as trust signal**：真实性本身是转化率工具（不是审美选择）
- **Accessibility compliance**：WCAG 对比度标准、alt text、色盲友好配色已成法规要求

## 3. 巴西/拉美电商视觉审美：Calor / Alegria / Vida

### 3.1 核心特征

| 维度 | 特征描述 |
|------|----------|
| **色彩** | 暖色调主导（橙/黄/珊瑚/热带绿）、高饱和度、多色混搭不冲突；节日/嘉年华色彩基因 |
| **光影** | 充沛日光感（即使棚拍也模拟阳光）、高光区域保留暖意、阴影偏暖不偏冷 |
| **人物** | 多人互动 > 单人摆拍；家庭/朋友/社区场景；笑容真诚外放、肢体语言丰富开放 |
| **生活场景** | 海滩/街头/市集/派对/厨房/后院烧烤——产品在真实使用情境中出现，而非孤立展示 |
| **情感基调** | Alegria（快乐）、Calor humano（人情味）、Vibra（活力）、Conexao（连接感） |
| **排版** | 圆润字体、手写元素、感叹号/emoji 使用频率高于欧美；促销信息视觉权重大 |
| **文化符号** | 热带植物、桑巴/足球元素、本地艺术家插画、葡萄牙语文案口语化亲切感 |

### 3.2 巴西 vs 其他拉美市场微调

| 市场 | 差异点 |
|------|--------|
| **巴西** | 最外向热情；色彩最饱和；社交/派对场景权重最高；Mercado Livre / Shopee BR 主导 |
| **墨西哥** | 稍内敛于巴西但仍温暖；传统工艺/民族图案融入更多；家庭场景 > 派对场景 |
| **哥伦比亚** | 介于巴西与墨西哥之间；城市时尚感更强；Medellin/Bogota 都市生活方式内容增长快 |
| **阿根廷** | 相对欧式/冷静；布宜诺斯艾利斯审美接近南欧；色彩饱和度低于巴西 |

### 3.3 注意事项

- **避免刻板印象**：不是所有拉美好物都要用热带元素；城市中产消费者同样接受极简/北欧风
- **肤色多样性**：巴西是全球种族混合度最高的国家之一，模特必须体现 pardo/preto/branco/amarelo 多元肤色
- **宗教/文化敏感**：天主教符号、非洲裔宗教元素（Candomble）需谨慎使用，避免猎奇化
- **支付/信任视觉**：Parcelamento（分期）标识、Pix 图标、Frete Gratis（免运费）徽章是巴西电商视觉的必备元素

## 4. Don Norman 情感化设计三层次在商品图中的落地

### 4.1 理论框架回顾

Don Norman 在《Emotional Design》(2004) 中提出情感处理的三个层次：

| 层次 | 定义 | 时间尺度 | 对应商品图目标 |
|------|------|----------|----------------|
| **本能层 (Visceral)** | 感官直接反应：好看/难看、吸引/排斥 | 毫秒级 | 第一眼吸引力：色彩、光影、构图、面孔 |
| **行为层 (Behavioral)** | 使用体验预期：好用/难用、有效/无效 | 秒-分钟级 | 功能可信度：产品细节清晰度、使用场景合理性、信息可读性 |
| **反思层 (Reflective)** | 意义建构：身份认同、价值观共鸣、记忆联想 | 天-年级 | 品牌忠诚度：故事感、文化符号、自我投射、社群归属 |

### 4.2 五种情感定位的视觉语言映射

#### 优雅（Elegant）

| 层次 | 视觉语言 |
|------|----------|
| 本能 | 低饱和中性色（驼/灰/象牙）；大面积留白；细腻材质特写（丝绸/皮革/金属光泽）；柔焦背景 |
| 行为 | 产品工艺细节微距；尺寸比例参照物；包装开箱仪式感序列图 |
| 反思 | 传承/匠心故事；创始人手写签名；限量编号；博物馆/画廊场景暗示 |
| **光** | 侧逆光勾勒轮廓；单光源戏剧感 |
| **色** | 单色/双色方案；金色/银色点缀 |
| **构图** | 黄金分割/对角线；不对称平衡 |
| **模特姿态** | 克制、静止、下巴微抬、目光远方；手部优雅持物 |

#### 甜美（Sweet）

| 层次 | 视觉语言 |
|------|----------|
| 本能 | 粉/桃/薰衣草/薄荷色；圆润形状；柔光无硬影；闪光/星芒/气泡元素 |
| 行为 | 产品可爱包装正面展示；使用过程趣味瞬间；尺寸小巧感强调 |
| 反思 | 少女心/童年怀旧/闺蜜分享；社交媒体打卡感；treat yourself 自我宠爱叙事 |
| **光** | 正面平光 + 环形补光；眼神光明显 |
| **色** | 糖果色渐变；白色打底提亮 |
| **构图** | 居中对称/圆形裁切；俯拍 flat lay |
| **模特姿态** | 微笑/嘟嘴/眨眼；双手捧脸/比心；头部倾斜 |

#### 运动（Sporty）

| 层次 | 视觉语言 |
|------|----------|
| 本能 | 高对比撞色（黑+荧光绿/橙/电光蓝）；动态模糊/速度线；汗水/水珠质感 |
| 行为 | 产品性能参数可视化；运动中实际使用抓拍；before/after 效果对比 |
| 反思 | 突破极限/自律/团队精神；运动员故事；赛事/训练场景；earned not given 价值观 |
| **光** | 硬光/聚光灯/明暗强烈对比；背光剪影 |
| **色** | 深色底 + 高饱和强调色；反光材质 |
| **构图** | 斜线/三角形动感构图；低角度仰拍增强力量感 |
| **模特姿态** | 发力瞬间/腾空/奔跑；肌肉线条可见；专注表情非微笑 |

#### 商务（Professional）

| 层次 | 视觉语言 |
|------|----------|
| 本能 | 深蓝/炭灰/酒红/墨绿；直线几何；精致质感（钢笔/皮质/金属扣）；整洁秩序感 |
| 行为 | 产品尺寸/容量标注；多场景适用展示（办公室/出差/会议）；搭配示范 |
| 反思 | 成功/效率/专业形象；职场进阶叙事；精英圈层认同；invest in yourself |
| **光** | 均匀柔光；无明显方向性；模拟办公环境照明 |
| **色** | 深色系为主；白色/浅灰辅助；避免荧光色 |
| **构图** | 网格/对齐/秩序感；三分法稳重构图 |
| **模特姿态** | 自信站姿/坐姿；手持公文包/笔记本；适度微笑但不过度亲和 |

#### 慵懒（Cozy/Lazy）

| 层次 | 视觉语言 |
|------|----------|
| 本能 | 暖米/奶茶/灰棕/烟粉；柔软织物纹理；暖色温（3200-4000K）；轻微失焦梦幻感 |
| 行为 | 产品包裹身体的触感暗示；居家使用场景（沙发/床/地毯）；时间停滞感 |
| 反思 | 慢生活/自我关怀/hygge/jomo；对抗内卷焦虑；允许自己休息许可感 |
| **光** | 窗边自然光/台灯暖光；光影斑驳（窗帘缝隙/树叶投影） |
| **色** | 大地色系；同色系深浅层次；避免冷色 |
| **构图** | 水平线稳定感；框中框（门框/窗框/毯子边缘）营造包裹感 |
| **模特姿态** | 蜷缩/倚靠/半躺；闭眼/低头看书/端杯；衣物宽松褶皱自然 |

### 4.3 三层次检验清单（商品图上架前自检）

- [ ] **本能层**：缩略图状态下是否仍具吸引力？色彩在手机屏幕上是否准确？
- [ ] **行为层**：产品关键信息是否在 1 秒内可读？尺寸/材质/用途是否有视觉证据？
- [ ] **反思层**：目标用户看到后能否说出"这就是给我这样的人用的"？是否触发了期望的身份联想？

## 5. 色彩心理学跨文化差异：美/韩/巴西三市场对比

### 5.1 核心颜色情感联想对照表

| 颜色 | 美国 | 韩国 | 巴西 |
|------|------|------|------|
| **红色** | 紧急/促销/激情/危险；Sale标签标配 | 喜庆/传统（婚礼/春节）但也关联警告；电商中使用较克制 | 热情/能量/庆祝；与绿色组合=国旗色，需谨慎避免政治联想 |
| **蓝色** | 信任/专业/科技/冷静；金融/B2B首选 | 稳定/现代/清爽；科技公司常用但饱和度偏低 | 和平/信赖；但与黄色组合=国旗色，商业使用需注意语境 |
| **绿色** | 自然/健康/环保/财富 | 自然/治愈/清新；美妆/健康品类偏爱低饱和绿 | 自然/丰饶/希望；国旗色成分，单独使用比红黄组合安全 |
| **黄色** | 乐观/警示/廉价感（双刃剑） | 温暖/活力但使用面积小；点缀多于主色 | 欢乐/财富/阳光；高饱和黄广泛接受，与紫色搭配=嘉年华经典 |
| **白色** | 纯净/简约/高端/医疗 | 纯洁/空灵/gamseong基底色；大面积使用是韩式标志 | 和平/宗教（Candomble白衣）；但纯白底可能显得冷清，需加暖 |
| **黑色** | 奢华/权威/神秘/mourning | 现代/都市/chic；高端品牌常用 | 庄重/正式；大面积黑可能关联丧事，需搭配亮色平衡 |
| **粉色** | 女性/甜美/乳腺癌意识月 | 柔美/年轻/romantic；男女皆可接受的柔和粉 | 温柔/浪漫/女性气质；亮粉（rosa choque）有强烈本土流行文化关联 |
| **紫色** | 皇室/灵性/创意/LGBTQ+ | 神秘/高贵/成熟；美妆品类常用 | 灵性/尊贵；嘉年华/宗教节日关联强 |
| **橙色** | 活力/友好/CTA按钮/万圣节 | 温暖/食欲/秋季；食品品类偏好 | 热情/创造力/社交；高度正面，广泛用于促销和社交场景 |

### 5.2 跨文化色彩应用原则

1. **没有通用色彩语义**：同一颜色在三市场的情感效价可能相反（如白色在韩国=纯洁，在巴西部分地区=宗教仪式）
2. **饱和度比色相更关键**：韩国偏好低饱和同色系，美国接受全饱和光谱，巴西偏好中高饱和暖色
3. **组合 > 单色**：色彩意义高度依赖搭配（巴西黄+绿=国旗，黄+紫=嘉年华；美国红+白+蓝=爱国）
4. **品类惯例优先于文化泛论**：美妆/科技/食品各有品类色彩规范，文化差异在品类框架内微调
5. **测试 > 假设**：A/B test 当地用户对色彩方案的真实反应，永远优于理论推演

### 5.3 实用建议

- **进入韩国市场**：将品牌主色降饱和 20-30%，增加中性色占比，避免大面积纯红/纯蓝
- **进入美国市场**：确保 CTA 色彩对比度 >= 4.5:1（WCAG AA），提供深色模式适配，考虑色盲友好替代色
- **进入巴西市场**：暖色温整体上调，促销色可用橙/黄但避开红绿/蓝黄国旗组合的大面积并置，加入本地肤色多样性
